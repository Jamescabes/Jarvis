# Visión de Producto (Product Vision)

## Casos de Uso Reales

### 1. El Ejecutivo Ocupado

"Jarvis, resúmeme los correos de la última hora y dime qué es urgente."
Jarvis no solo lee, *entiende* la prioridad y filtra el ruido.

### 2. Automatización del Hogar

"Me voy a dormir."
Jarvis apaga luces, activa la alarma, pone el teléfono en 'No Molestar' y programa el café para las 7:00 AM.

## User Journeys

1. **Onboarding**: El usuario descarga la app -> Login biométrico -> Saludo personalizado ("Bienvenido de nuevo, Señor").
2. **Daily Driver**: El usuario interactúa por voz mientras conduce, y por texto en reuniones.

## Diferenciación

- **No corporativo**: No intentamos vender productos (Amazon) ni recolectar datos (Google).
- **Proactivo**: Jarvis sugiere acciones antes de que el usuario las pida ("Está empezando a llover, ¿pido un Uber?").

## Evolución del Producto

- **Fase 1**: Chatbot inteligente con UI premium.
- **Fase 2**: Agente con capacidad de acción en el teléfono.
- **Fase 3**: Ecosistema completo (Hardware propio).
