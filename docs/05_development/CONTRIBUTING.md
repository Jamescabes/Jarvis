# Cómo Contribuir (Contributing)

¡Gracias por tu interés en mejorar Jarvis!

## Flujo de Trabajo

1. **Fork** del repositorio.
2. Crea una rama (`git checkout -b feature/nueva-magia`).
3. Haz tus cambios (commits pequeños y claros).
4. **Push** a tu rama.
5. Abre un **Pull Request (PR)**.

## Issues

- Antes de empezar, revisa los Issues abiertos.
- Si encuentras un bug, repórtalo con pasos para reproducir.
