# Privacidad (Privacy)

## Enfoque Privacy-First

Jarvis se diferencia de la competencia por ser una herramienta *del* usuario, no *sobre* el usuario.

## Qué Datos se Usan

- **Voz/Texto**: Solo se procesa cuando la "keyword" es detectada o la app está activa.
- **Contexto**: Ubicación, hora, calendario (solo bajo demanda).

## Qué NO se Almacena

- Audio crudo (se descarta tras la transcripción).
- Datos enviados a LLMs externos (se usan cláusulas de "No-Training" con proveedores como OpenAI/Anthropic Enterprise).

## Control del Usuario

El comando "Jarvis, borra mi memoria reciente" purga inmediatamente el contexto de corto plazo y los logs de sesión asociados.
